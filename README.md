## 🎮 Overview

This is a personal designer portfolio site built to showcase projects, skills, and experience in a clean, visually engaging layout. It's fast, fully responsive, and deployed on Vercel for instant global access.

## ✨ Features

- 🖼️ Project/work showcase with images and descriptions
- 📱 Fully responsive design across desktop, tablet, and mobile
- ⚡ Fast load times powered by Vite's build tooling
- 🎨 Clean, modern UI tailored for showcasing design work
- 🔗 Direct links to live projects and case studies
- 📩 Contact section for inquiries and collaboration

## 🌐 Deployment

This project is deployed on [Vercel](https://vercel.com/). Every push to the main branch triggers an automatic build and deployment.

To deploy your own copy:

1. Push this repo to GitHub.
2. Import it into [Vercel](https://vercel.com/new).
3. Vercel auto-detects the Vite config and deploys — no extra setup needed.
